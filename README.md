# よみキャン運営虎の巻

よみたん放課後キャンパスの送迎運行計画を、メンバーが見るためのアプリです。

- アプリ: https://k-three.github.io/yomicam-toranomaki/app/
- 閲覧にはメンバー共有のパスワードが必要です（運行管理担当にお問い合わせください）
- データは Firebase（Firestore）にあり、このリポジトリには個人情報を置いていません

## 配布ページの廃止（2026-10-06）

以前あった「配布ページ」（毎営業日12時に生成していた暗号化スナップショット）は廃止しました。

アプリへ自動で移動するだけのページです。

## 🚨 緊急

ヘッダーの「🚨 緊急」から、所在不明・ケガ・体調不良・交通事故などの緊急を出せます。
送迎記録アプリ（https://k-three.github.io/yomicam-driving/ ）の「🚨 緊急」と同じ画面です。

- 電話（設定した緊急連絡先、ケガ・事故なら 119／110）をすぐかけられる
- 「緊急対応中にする」で、送迎記録と虎の巻のすべての画面の先頭に赤い帯が出て、Slack に一報が出る
- この端末で送迎記録にログインしていればそのまま使える。していなければ最初の1回だけ
  送迎記録のパスワードを聞かれる
- 帯の「対応・解決」から、解決・誤報の取り消しができる

仕組みは送迎記録側の `alert.js` と `sos-widget.js` で、このリポジトリにはボタン1つと
読み込みの1行だけを置いています。帯の合図には個人情報は入っていません
（緊急中かどうか・開始時刻・種別だけ）。
