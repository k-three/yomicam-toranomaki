# よみキャン運営虎の巻

よみたん放課後キャンパスの送迎運行計画を、メンバーが見るためのアプリです。

- アプリ: https://k-three.github.io/yomicam-toranomaki/app/
- 閲覧にはメンバー共有のパスワードが必要です（運行管理担当にお問い合わせください）
- データは Firebase（Firestore）にあり、このリポジトリには個人情報を置いていません

## 配布ページの廃止（2026-10-06）

以前あった「配布ページ」（毎営業日12時に生成していた暗号化スナップショット）は廃止しました。
メンバーはアプリ本体を直接使います。`https://k-three.github.io/yomicam-toranomaki/` は
アプリへ自動で移動するだけのページです。

## 緊急時の帯

送迎記録アプリ（https://k-three.github.io/yomicam-driving/ ）の「🚨 緊急」で
「緊急対応中」にすると、このアプリの画面の先頭にも赤い帯が出ます
（`alert.js` が1分ごとに合図を読みに行く。合図には個人情報は入っていません）。
